## 2024-05-19 - Regex matching performance versus manual Python parsing
**Learning:** In Python, applying regular expressions using compiled C extensions is often much faster than manual character-by-character string parsing or multiple index-based `rfind` string checks. We attempted to optimize `object_key_from_token` by removing regex usage or using fast-path checks for `.obj`, but discovered the `.obj` regex was surprisingly fast. Conversely, for parsing space-separated tokens where regex isn't feasible, using the C-optimized `.split()` method on strings without quotes is dramatically faster than looping through the string in Python.
**Action:** When working on token or log parsing optimization, avoid writing complex character-based loops or slicing if Python's native `split()` or optimized `re` modules can achieve the same logic directly. Always benchmark fast-path assumptions before committing them.
